物流轨迹中心与物流规则改造 PRD

统一查询正向/逆向物流，独立维护轨迹关键词归类规则
版本：V1.2评审稿评审日期：2026-07-23目标终端：B 端 ERP Web
本需求对应两个页面：物流轨迹中心负责查询与查看轨迹；物流规则负责维护通用轨迹识别规则。通用轨迹配置不得出现在物流轨迹中心模块内。

1. 需求概述

1.1 背景

现有物流页面以正向物流列表为主，正向发货、逆向退件和异常轨迹的展示口径不一致。物流运营、客服和退件仓需要在稳定的 ERP 列表工作区内完成查询、异常定位和轨迹查看。

1.2 目标

目标说明优先级
统一查询在物流轨迹中心切换正向物流和逆向物流，分别展示对应状态与字段。P0
异常归类承运商原始轨迹归一为业务节点；正向派送失败、丢件、破损等归入“包裹异常”。P0
规则维护将“丢件”“派送失败”等通用关键词配置迁移到独立物流规则页面。P0
降低跳转包裹详情使用右侧 Drawer，不为查看轨迹新增独立页面。P0

1.3 非目标

  • 不在物流轨迹中心增加通用轨迹配置按钮、弹窗或配置面板。
  • 不在本期实现退件入库、质检、退款、理赔、售后审批页面。
  • 不改变承运商原始轨迹，不将技术堆栈直接展示给业务用户。
  • 不新增角色切换器、页面状态切换器或调试面板。

2. 页面范围与边界

页面线上参考路径主任务本期范围
物流轨迹中心/yh-logistics/logisticsTrajectory查询包裹、定位异常、查看正向/逆向轨迹方向切换、状态筛选、条件查询、列表、详情 Drawer、同步/导出/备注反馈
物流规则/yh-logistics/logisticsRules维护轨迹关键词与业务状态的归类规则规则列表、关键词筛选、编辑抽屉、保存规则、规则更新时间
明确边界：物流轨迹中心只消费规则结果，不提供规则编辑入口；物流规则页面只维护识别规则，不承担包裹查询和轨迹详情查看。

5. 物流规则需求

5.1 页面目标

在独立的物流规则页面维护轨迹原文与业务状态的归类规则，避免配置能力和包裹查询能力混在同一个模块中。

5.2 页面功能

功能要求优先级
规则列表展示规则名称、规则类型、匹配关键词、归类状态、启用状态、最近更新时间、操作人。P0
规则筛选支持按规则名称或关键词查询，支持重置。P0
编辑规则点击“编辑”打开右侧 Drawer，维护关键词；中文逗号、英文逗号和换行均可分隔。P0
保存规则至少保留一个关键词；保存后更新时间和操作人刷新。P0

5.3 初始规则

规则名称匹配关键词示例归类结果
丢件丢件、包裹丢失、无法找回、package lost、lost parcel包裹异常
派送失败派送失败、投递失败、delivery failed、unable to deliver包裹异常

5.4 页面边界

  • 物流规则页面不展示包裹列表和轨迹详情。
  • 规则变更只影响后续轨迹识别，历史结果不回溯。
  • 新增规则、启停规则和删除规则的正式权限与流程待确认；本期原型只覆盖已有规则编辑。

6. 数据与状态定义

字段类型说明
directionenumforward 正向；reverse 逆向。
statusenum按方向返回一级业务节点；前端不直接修改状态。
returnStageenum正向退回节点：退回中、退回签收、包裹异常。
exceptionTypeenum正向：查不到轨迹、派送失败、丢件、破损、轨迹同步失败；逆向：妥投失败、破损丢件。
returnTypeenum仅逆向使用：原包裹退回、客户退回。
keywordConfigobject物流规则页面维护的关键词集合，不在轨迹中心编辑。
rawDescriptionstring承运商原始描述，只读展示或详情展开，不覆盖标准节点。

6.1 状态流转

已交运 → 未上网 → 已上网 → 已交航 → 已到达目的国 → 已签收
任意未终态 → 轨迹同步失败 → 重试成功后恢复原状态
任意状态 → 退回 → 退回中 / 退回签收 / 包裹异常
退回中 → 逆向退回中 → 逆向已签收 / 逆向包裹异常

8. UI 与原型约束

维度要求
视觉基线中文 B 端 ERP；浅灰布局背景、白色面板、紧凑表格、克制圆角和阴影。
组件ErpShell、PageHeaderBar、QueryFilterBar、DataTablePanel、DetailDrawer、Tabs、Segmented、Tag、Timeline。
按钮按新版语义使用 color + variant 组合；主操作使用实心主色按钮。
状态标签必须使用 .tag 与 .tag--*；不能只依赖颜色表达状态。
禁止不使用原生 select、浏览器 alert、营销型指标卡、角色切换器、调试面板。
原型文件物流轨迹中心；物流规则。

9. 验收标准

  1. 物流轨迹中心不出现“通用轨迹配置”按钮、弹窗或配置表单。
  2. 物流规则页面可展示丢件、派送失败两条规则，并可打开编辑 Drawer。
  3. 规则关键词支持中文逗号、英文逗号和换行分隔，至少保留一个关键词才能保存。
  4. 正向物流一级状态包含“退回”；其二级节点为“退回中、退回签收、包裹异常”，不再展示“退回破损丢件”。
  5. 正向物流“包裹异常”二级类型包含查不到轨迹、派送失败、丢件、破损、轨迹同步失败。
  6. 逆向物流一级状态包含退回中、已签收、包裹异常；退回类型包含原包裹退回、客户退回。
  7. 正向/逆向切换、查询、重置、详情 Drawer、ESC/遮罩关闭均可用。
  8. 页面无控制台错误，样式守卫和脚本语法检查通过。

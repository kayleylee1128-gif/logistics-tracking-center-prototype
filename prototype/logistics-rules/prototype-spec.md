# 物流规则 · prototype-draft

> 原页面参考：`https://erp.cloudebox.cn/yh-logistics/logisticsRules`

## 页面目标

在物流规则原页面内维护物流轨迹关键词归类规则。通用节点通过右上角入口打开 Modal，规则保存后仅影响后续轨迹识别，不在物流轨迹中心列表内提供配置入口。

## 本轮范围

| 页面区域 | 说明 |
|---|---|
| 规则列表 | 展示规则名称、类型、匹配关键词、归类状态、启用状态和更新时间 |
| 筛选区 | 支持规则名称 / 关键词查询和重置 |
| 编辑抽屉 | 编辑关键词，支持中文逗号、英文逗号或换行分隔 |
| 规则状态 | 当前原型展示已启用规则；后续可扩展启停操作 |

## 当前规则

- 丢件：命中后归类为“包裹异常”。
- 派送失败：命中后归类为“包裹异常”。

## 通用规则配置弹窗

- 页面右上角新增“配置通用规则”按钮。
- 点击后打开可编辑弹窗，左侧按节点切换，右侧展示并编辑节点名称、归类结果、适用范围、规则说明、匹配关键词、启用状态和最近更新时间。
- 当前覆盖“退回”“丢件”“派送失败”三个节点；“退回”归类为退回节点，“丢件”和“派送失败”归类为“包裹异常”。
- 支持“手动添加”创建新的通用节点，保存后立即加入左侧节点列表。
- 支持点击遮罩、关闭按钮和 ESC 关闭弹窗；规则变更只影响后续轨迹识别。

## 页面边界

- 物流轨迹中心只负责查询、筛选和查看轨迹，不展示通用轨迹配置入口。
- 规则配置不回溯历史轨迹结果。
- 不在正式页面加入角色切换、状态切换或调试面板。

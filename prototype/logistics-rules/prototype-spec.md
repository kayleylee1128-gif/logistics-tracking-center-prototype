# 物流规则 · prototype-draft

> 原页面参考：`https://erp.cloudebox.cn/yh-logistics/logisticsRules`

## 页面目标

在物流规则原页面维护物流商、物流渠道、映射单号、查询状态和四类轨迹取值规则。通用配置通过页面右上角入口打开 Modal，不新增独立页面。

## 页面范围

| 页面区域 | 说明 |
|---|---|
| 规则列表 | 展示物流商、物流渠道、映射单号、查询状态、上网/交航/到达目的国/签收取值摘要、最近更新时间 |
| 筛选区 | 按物流商、物流渠道、查询状态筛选；支持关键词查询和重置 |
| 添加/编辑规则 Modal | 参考线上“添加规则”表单，维护基础字段、四个取值设置页签和预警规则 |
| 轨迹取值规则 | 支持按第几条轨迹判断，或按轨迹关键词、排除关键词判断；关键词可逐条添加和删除 |
| 预警取值规则 | 分别配置未上网、未交航、未到达目的国、未签收的预警天数 |

## 基础字段

- 物流商：必填，支持选择中塔物流、安捷利美、USPS、DHL 等物流商。
- 物流渠道：必填，按物流商选择对应渠道。
- 查询状态：开关控制规则是否参与后续轨迹查询。
- 映射单号：必填，支持物流单号、跟踪号、平台单号。

## 四类取值设置

- 上网取值设置、交航取值设置、达到目的国设置、签收取值设置均使用同一套表单结构。
- 轨迹取值支持“选定第 N 条轨迹”或“轨迹关键词”两种方式。
- 关键词支持中文逗号、英文逗号和换行分隔；排除关键词单独维护。
- 预警规则分别配置对应状态的预警天数，提示文案展示对应时效计算口径。

## 交互

- 页面右上角“配置通用规则”打开已有规则配置；表格“编辑”打开对应规则；“新增规则”打开空白添加表单。
- 点击四个页签切换对应轨迹取值规则，添加/删除关键词即时反映在当前表单。
- 点击“确定”校验物流商、物流渠道、映射单号和关键词配置后保存；保存只影响后续轨迹识别。
- 支持取消、关闭按钮、遮罩和 ESC 关闭弹窗。

## 页面边界

- 物流轨迹中心只负责查询、筛选和查看轨迹，不展示规则配置入口。
- 不接入真实接口；列表和配置为可交互 Mock 数据。
- 不使用原生 select、浏览器 alert、角色切换器或调试面板。
